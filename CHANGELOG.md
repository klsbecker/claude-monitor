## [1.0.0] - 2026-11-26

First public release.

### Added

- Session (5 h) and weekly usage on a strip in the Windows taskbar, next to the notification area.
- Notification-area icon mode with both numbers stacked.
- Hover card with progress bars, reset times, usage charts, hover read-out and a pace forecast.
- Notifications at a chosen usage level and when a limit resets.
- Menu options: limits to show, red level, refresh interval, icon color, position and height, background
  plate, language, start with Windows, clear history.
- English, Brazilian Portuguese and Spanish, following the Windows language by default.
- Automatic refresh of an expired Claude Code token, and an offer to install Claude Code and sign in.
- Choice of the Claude Code folder to read the sign-in from (several accounts), with one history per account.
- `--demo` mode with made-up data.
- Migration of settings, autostart and history from the earlier private build ("ClaudeUsage").
